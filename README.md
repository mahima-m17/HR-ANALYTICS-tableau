# HR Analytics Dashboard | Tableau

## 📌 Project Overview
This project focuses on analyzing HR data using Tableau to understand employee attrition, job satisfaction, and workforce demographics through interactive visualizations.

## 🎯 Objectives
- Analyze employee attrition across departments.
- Explore attrition based on education fields.
- Understand job satisfaction ratings.
- Analyze employee distribution across different age groups.
- Present key HR metrics using interactive visualizations.

## 📊 Dashboard Features
- Department-wise Employee Attrition
- Education Field Analysis
- Job Satisfaction Rating
- Employee Age Group Analysis
- Key HR Indicators (KPIs)
- Interactive Data Visualizations

## 🛠️ Tools & Technologies
- Tableau
- Data Visualization
- Exploratory Data Analysis (EDA)
